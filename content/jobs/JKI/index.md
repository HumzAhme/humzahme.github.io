- 📡 Analyzed UAV and terrestrial LiDAR data to measure vegetation structure in forest and plantation research, and supported field experiments on tree stress responses.
- Built an end-to-end Python pipeline (point cloud processing → tree localization → height extraction → crown segmentation) to detect and measure 444 individually surveyed young conifer seedlings from drone LiDAR
- Compared height estimates across 7 flight-altitude combinations (30 m / 60 m, single and merged flights) using statistical testing (Wilcoxon), showing that 60 m data alone underestimates seedling height
- Processed terrestrial laser scanning (TLS) and UAV-LiDAR data for tree-diversity plots: ground classification, canopy height models, foliage height diversity, and comparison with LAI field measurements
- Applied watershed and deep-learning (DeepForest) tree detection and cross-validated the results
- Ran point-density analyses to choose processing resolution from the data rather than assumptions
- Wrote verification tools and documentation so results can be reproduced and checked
- Flew UAV missions collecting LiDAR and RGB imagery
- Manually verified and corrected detected tree positions in QGIS
- Supported a VOC sampling experiment on Norway spruce under artificial drought (closed-loop bark systems, Gerstel Twisters, 20 trees, Friedrichshöhe)
- Contributed to an experiment on Diplodia fungus effects in pine saplings under normal vs. water-stress conditions, a relevant forest-health issue in Saxony-Anhalt
- Tools: Python (NumPy, SciPy, laspy, rasterio), QGIS, CloudCompare, point cloud analysis, statistics, scientific documentation
